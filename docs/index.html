Yucca DPU

智算中心算力运营变革的关键

Yucca DPU 拥有强大弹性裸金属能力，可精细隔离物理 AI 服务器的网络、存储资源，实现多用户间高效流转，如同智算中心的“智能中枢”。

  • 支持 SRIOV、OVS Offload 等网络加速技术
  • 支持 Ceph、iSCSI 等存储场景
  • 融合 GPU Direct RDMA、PCIe P2P 与虚拟化加速
  • 提供 libvirt 和 CNI 管控适配

Yucca SuperNIC

AI 训练网络的高速引擎

Yucca SuperNIC 专为解决以太网 AI 训练大规模数据传输难题，支持 GPU Direct RDMA、标准 RoCEv2、自研及开放 UEC 协议。

  • 总带宽高达 2x200Gbps 甚至更高
  • 转发速率达 250Mpps
  • 集成 OVS 网络加速与多种 RDMA 技术
  • 支持 PCIe Gen5x16 Host 接口与 Virtio Net 设备类型
